# jtagid 界面文案（UTF-8，key<TAB>文本）
# 只管 tk_tunnel 窗口（jtagid_tk_ui.tcl）用到的键；缺失的键会用代码里的英文默认值。
btn_identify	识别 FPGA 型号
btn_clear	清除过滤
lbl_candidates	BSDL 候选（按封装/型号/关键字过滤后，选中要用的那一份）
lbl_package	封装
lbl_model	型号
lbl_keyword	关键字
col_package	封装
col_irl	IRL
col_bsr	BSR
col_file	BSDL 文件
all	全部
status_ready	就绪：点「识别 FPGA 型号」开始
status_identifying	正在识别
status_done	识别完成
status_failed	失败
win_title	jtagid —— 边界扫描识别 FPGA 型号（tk_tunnel 原生窗口）
col_cells	cells
status_selected	已选定
status_waiting	正在连接 Vivado 后端…
status_nobackend	Vivado 没有响应：请在 Vivado IDE 的 Tcl Console 里 source 本文件（-mode tcl 的纯 Tcl 窗口不会响应界面）
col_model	型号
sku_line_die	硅片
sku_line_models	同 IDCODE 型号
sku_line_same	结论
sku_same_die	同一颗硅片：边界扫描（IDCODE/BSDL/BSR）无法区分这几个型号
sku_single	只有这一个型号使用该 IDCODE
sku_line_ps	PS 侧差异
sku_line_pl	PL 资源
sku_line_this	本行型号
sku_line_sib	同硅片候选
sku_line_entity	实体名
sku_how_title	如何最终确定这个 SKU
sku_how_1	1) 看芯片丝印：型号/速度/温度都有，例如 XCZU3EG-1SFVC784I
sku_how_2	2) 看板卡 BOM / 原理图 / 丝印（汽车级 XAZU… 与商用 XCZU… 同硅片）
sku_how_3	3) PS 跑 Linux 时：有 Mali GPU（设备树 gpu@fd4b0000 / dmesg 里的 mali）→ EG/EV；没有 → CG
sku_how_4	4) 也可以在弹窗里用封装/型号直接筛到那一行，再按「使用这份 BSDL」
lbl_bound	已绑定的器件 ↔ BSDL
btn_rechoose	选择 BSDL
status_bound	已绑定
status_nobound	尚未绑定 BSDL
status_saved	已写入 bindings.txt
status_pick_hint	点一行选中，再按「使用这份 BSDL」完成绑定
status_pick_row	请先选中一行
dlg_title	选择 BSDL 并与器件绑定
btn_use	使用这份 BSDL
btn_cancel	取消
lbl_bind_to	绑定到器件
status_nocand	还没有候选：先点「识别 FPGA 型号」
tag_bound	已绑定
